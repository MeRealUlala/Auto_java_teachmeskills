UI test cases for SauceDemo login page

--------------------------------------------------

Positive test cases:

1. Login with valid credentials: standard_user / secret_sauce
Expected result: User is redirected to Products page.

2. Login with valid credentials: problem_user / secret_sauce
Expected result: User is redirected to Products page.

3. Login with valid credentials: visual_user / secret_sauce
Expected result: User is redirected to Products page.

Expected result: Error message "Epic sadface: Username and password do not match any user in this service" is displayed.

Expected result: Error message "Epic sadface: Password is required" is displayed.

6. Login with empty username and empty password
Test data: empty username / empty password
Expected result: Error message "Epic sadface: Username is required" is displayed.

--------------------------------------------------

Expected result: Correct error message is displayed for each invalid data set.
